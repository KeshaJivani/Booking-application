# Booking App (Frontend)

Simple static frontend for a travel booking site. This repository contains HTML pages for browsing and booking flights, stays, cars, and more.

## Contents
- index.html — site homepage
- attractions.html, attractiondetails.html
- stays.html, viewdetails.html, listproperty.html
- flights.html
- carrentals.html, cardetails.html
- booknow.html, payment.html, successfullybook.html
- signin.html, register.html, contact.html, notfound.html

## Quick Start

Open the site locally by serving the folder and visiting http://localhost:8000 in your browser.

Using Python 3 (recommended):

```bash
python -m http.server 8000
```

Then open:

- http://localhost:8000/index.html

## Notes
- This is a static frontend — no backend included in this folder.
- To make changes, edit the corresponding `.html` files and refresh the browser.
